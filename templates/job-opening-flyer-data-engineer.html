KEY RESPONSIBILITIES

  • Design and optimize ETL/ELT pipelines using Snowflake for data ingestion, transformation, and loading.
  • Build and maintain scalable data architectures supporting analytical and operational workloads.
  • Monitor, troubleshoot, and optimize data pipeline performance and query execution.
  • Implement data validation frameworks to ensure data accuracy and consistency.
  • Collaborate with data analysts, scientists, and business stakeholders on requirements and solutions.
  • Maintain comprehensive technical documentation for data processes and systems.
  • Implement monitoring and alerting systems; provide production support for data pipelines.
  • Participate in peer code reviews and contribute to best practices.

REQUIRED SKILLS

  • 3–5 years of hands-on experience in data engineering or ETL development.
  • Proven expertise with Snowflake — database design, queries, performance tuning, and data loading.
  • Understanding of data warehouse concepts, dimensional modeling, and Data Vault concepts.
  • Advanced SQL proficiency for complex queries, optimization, and data manipulation.
  • Strong experience with Python for data pipeline development.
  • Experience with cloud environments, specifically Azure.
  • Familiarity with workflow orchestration tools such as Airflow or dbt, and Git.
★ Experience with Azure Databricks or Apache Spark, CI/CD practices, an Azure Data Engineer Associate or Snowflake certification, and Agile/Scrum experience are all pluses.
